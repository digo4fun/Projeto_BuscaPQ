# Projeto BuscaPQ - LinkedIn Professional Search

## Descrição
Aplicação para busca de profissionais no LinkedIn baseada em skills, senioridade e localização.

## Funcionalidades
- Busca de profissionais no LinkedIn por palavras-chave, senioridade e localização
- Seleção de perfis para entrevistas
- Armazenamento de perfis selecionados no banco de dados
- Visualização e gerenciamento de perfis salvos

## Tecnologias
- Backend: Java Spring Boot
- Frontend: JavaScript, HTML, CSS
- Banco de dados: H2 (em memória)

## Como executar
1. Execute o backend: `./mvnw spring-boot:run`
2. Abra o arquivo `frontend/index.html` no navegador
3. Acesse a aplicação em `http://localhost:8080`
